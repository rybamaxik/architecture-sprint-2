Файлы со схемами № 1...5 лежат в папке drawio (файлы task1.drawio ... task5.drawio).

В папке mongo-sharding - проект по схеме № 1 (приложение + шардированная Монга).

В папке mongo-sharding-repl - проект по схеме № 2 (приложение + шардированная Монга с репликацией внутри шардов).

В папке sharding-repl-cache - проект по схеме № 3 (приложение + шардированная Монга с репликацией внутри шардов + один инстанс Redis).

Во всех папках есть README. Наиболее полное описание находится в README в папке sharding-repl-cache.
