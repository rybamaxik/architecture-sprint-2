# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Инициализируем репликацию и шардирование Монги и сразу же заполняем mongodb данными:

```shell
cd scripts
bash ./mongo-shard-repl-init.sh
```

После заполнения данными скрипт выполняет также запрос на получение количества документов в коллекции helloDoc во всех репликах первого шарда и во всех репликах второго шарда (всего 6 инстансов Монги). Сложив количества попарно, получаем три раза по 1000 документов (если запускаем с нуля).

Далее запустим скрипт, который при помощи curl делает два раза запрос пользователей (/helloDoc/users), замеряя общее время запроса, причем второй раз запрос занимает значительно меньше времени из-за кэширования в Redis (смотреть нужно на поле time_total):

```shell
cd scripts
bash ./mongo-check-caching.sh
```

## Что запускается в докере

pymongo_api на порту 8080 - приложение
redis_1 на порту 6379 - инстанс Redis для кэширования
configSrv на порту 27019 - сервер конфигурации для кластера Монги
shard1_1, shard1_2, shard1_3 на портах 27031, 27032, 27033 - три реплики первого шарда Монги
shard2_1, shard2_2, shard2_3 на портах 27041, 27042, 27043 - три реплики второго шарда Монги
mongos_router на порту 27017 - роутер кластера Монги

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
